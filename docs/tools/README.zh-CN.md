# 工具管理

[English](README.md) · **中文** · [日本語](README.ja.md)

每个 agent CLI 都把自己的 skills、MCP server、hooks 和全局指令文件存在磁盘的某个角落。装几个工具、换着用几个月，就没人说得清现在到底加载了什么 —— 同一个 skill 在三个目录里各有一份，某条链接指向的东西早被删了，某个只配过一次的 server 还在你已经忘掉的那个 agent 里跑着。

这个页面把它们摊在一起，并且让你能动手收拾。

**入口**在侧栏底部的扳手图标，或者按 `⌘K`。

---

## Skills

![Skills 面板](../screenshots/tools-skills.png)

顶上那一条是这台机器的体检结果：45 个 skill，**28 个重复**、**12 个绕路才能到**、**1 个指向不存在的地方**。点任意一格就能把列表筛成只剩这一类。

选中一个 skill，右边把动手之前该知道的都摆出来：

- **启用于** —— 哪几家 agent 真能看见它。在这儿直接开关。
- **内容** —— 文件实际在哪。可能不止一份。
- **引用** —— 所有指向它的链接，以及中间经过了什么。
- **风险点** —— 从 skill 里扫出来的命令，可疑的会被标出来。代码块里当例子写的 `rm -rf` 比可执行脚本里同一行降一档，这样角标才还有意义。

排序支持**时间倒序 / 时间正序 / 按名称**，置顶的不受影响。

### 搬进主 store

![搬进主 store](../screenshots/tools-skills-adopt.png)

skill 散在各个目录里，是后面一堆麻烦的根源。这个操作把它归拢到你的主 store，原地留一条链接，所以什么都不会因此失效。

动手之前你先看到完整步骤 —— 这里是一次 `move` 加一次 `link`。不按按钮就一个字节都不写。顶上的**全部搬进主 store**是整批做。

### 修链接

![修链接](../screenshots/tools-skills-repair.png)

**绕路**指的是一条链接指向了另一条链接。它平时能用，直到某天突然不能用，而那时候很难查出 skill 为什么消失了。

修复会让链接直接指向真正存放文件的目录。图里 `~/.claude/skills/three` 原本要先经过 `~/.skills-manager` 才能到 `~/.cc-switch`，修完就是直达。

### 删除

![删除](../screenshots/tools-skills-delete.png)

死链就是这么来的：某个工具删掉了 skill 的目录，却把指向它的链接全留在原地。

这里的删除会**先解掉每一条引用，再删掉每一份内容**，并且开始之前把完整清单给你看。图里这个 skill 一查发现同时住在三个 store 里。如果你只想删全局那份、保留项目那份，也可以在**内容**列表里单独删掉其中一条。

## MCP

![MCP 面板](../screenshots/tools-mcp.png)

七家 agent 的 MCP server 汇总成一个列表，不管原来写在 JSON 还是 TOML 里。

- **上下文预算** —— 你还没开始打字，这些 server 就先吃掉多少上下文。图里一个 server 是 29 个工具、约 5700 token。
- **启用于** —— 哪几家在跑这个 server，以及是哪个文件让它跑起来的。注意 **Grok Build · 兼容读取**：Grok 默认会读 Claude 的配置，所以你加给 Claude 的 server 在它那边也跑着 —— 这件事平时完全看不见。
- 新增、编辑、删除、启停、同步给别家 —— 每一项都先给你看会改哪些文件。
- 长得像 token 或密钥的值默认打码，要看才显示。

## 发现 skills

![发现面板](../screenshots/tools-discover.png)

搜 [skills.sh](https://www.skills.sh)，装**之前**先把 skill 看清楚 —— 描述、文件清单、哪个 commit、在仓库里的哪个位置。

点**复制并安装**会在旁边拉起一个终端，把命令打进去。你看着它跑，随时 `Ctrl-C` 停掉。它会停在自己那句「装到哪几个 agent？」等你选 —— 这一步应用不替你回答。

## Hooks

![Hooks 面板](../screenshots/tools-hooks.png)

hooks 按命令归并，不按文件。图里第一条是一个脚本挂在 4 家 agent 的 9 个事件上 —— 显示成一行，而不是二十一行。

- 用真实 payload **试跑**一个 hook，直接看输出、退出码和耗时。
- 可以整条删掉，也可以只删它挂在某一处的那个落点。
- 本应用自己装的 hook 会被标出来并防误删。

## 全局配置

![全局配置面板](../screenshots/tools-memo.png)

`CLAUDE.md`、`AGENTS.md`，以及它们 import 进来的一切。

- **回退** —— opencode 自己没有这个文件，于是读 Claude 的。改那个文件等于同时改了两家。
- **未创建** —— 这家支持，只是你还没建。
- **片段** —— 被别人用 `@import` 引进来的文件。
- **额外读取** —— 不在约定路径上，但某家 agent 照样会加载的文件。

同名文件内容漂移了会被标出来，可以并排看差异，也可以一键以某一份为准同步过去。

## 配置集

顶栏的归档图标可以把你这套配置导出成一个能发给别人的文件。**值一律不导出** —— 同事拿到的是配置的形状，不是你的 API key。导入时由你勾选每一条装给哪几家。

---

## 两条始终成立的规则

**不确认就不写盘。** 每个操作都先把会改哪些文件摆出来，随时可以取消。

**不动你已有的内容。** 只重写本应用自己那几个键，原文件在旁边留一份备份；如果文件在读进来之后被外部改过，这次写入会被拒绝，而不是盖掉你的改动。

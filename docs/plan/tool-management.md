整页面板，管本机七家 agent（claude / codex / grok / agy / opencode / kimi / pi）散在各处的配置。
第三个 tab「发现 skills」的细节在 [skill-registry.md](./skill-registry.md)。

## 一、壳

- [x] 入口在侧栏底部，和设置同一行；`⌘K` 也能开合
- [x] 整页覆盖式打开，不是弹框 —— 五个面板信息量都不小
- [x] 五个 tab：`mcp` / `skills` / `discover` / `hooks` / `memo`（`TOOL_TABS`）
- [x] 统一的 master-detail 骨架：健康条 + 列表列 + 可拖分隔条 + 详情列，五个面板共用
- [x] 顶栏搜索按当前 tab 切占位文案；**切 tab 清搜索词、保留 agent 过滤器** —— 四个面板搜的不是一类东西，带着上个 tab 的关键词过去多半零结果；而「我关心哪几家」跨 tab 一直成立
- [x] 「只看某个 agent」的过滤器，一处生效；**空集当全选**，点到最后一个不会突然变空
- [x] 面板挂上后等列表第一次有东西，自动选中第一条 —— 否则开面板看到的是右边一句「没选中任何东西」
- [x] 列表列宽度持久化（拖拽中不落盘，松手才写）；列表 / 详情各有骨架屏

## 二、MCP 面板

- [x] 读七家的配置（JSON / TOML 两种格式），归一化成同一个列表
- [x] **格式挂在来源上，不挂在 agent 上** —— 同一家可能既有 JSON 又有 TOML 的来源
- [x] 作用域三档：user / project / local；来源三态：自己的 / 共享的 / 兼容读来的
- [x] **标出来源级联**：grok 默认会合并读 `~/.claude.json`，用户在 Claude 里加一条，grok 那边会跟着多出来
- [x] opencode 的 `command` 是数组（命令和参数混在一起）、env 键叫 `environment` —— 唯一需要拆/拼的一家
- [x] kimi 的 MCP 在独立的 `mcp.json`，且必须解析 `KIMI_CODE_HOME`，不能假定 `~/.kimi-code`
- [x] token 预算条：把每个 server 的工具数和大致 token 摆出来，让用户**看见成本并且方便关掉**
- [x] **打开面板不启动任何 server** —— 不做 `tools/list` 握手
- [x] 凭据按键名打码，默认不显示；本机 `~/.claude.json` 里就躺着明文 token
- [x] 解析失败不吞：一个坏逗号让一家的 server 整片消失是最坏的结果，坏了要报出来
- [x] 写入：新增 / 编辑 / 删除 / 启停 / 跨 agent 同步，全部 dry-run 先出计划框
- [x] **只换 `mcpServers` 那一段，别的字节一个不动**（`~/.claude.json` 本机 187 KB / 5541 行）
- [x] TOML 一个多余的键都不写 —— codex 的结构体没有 `type`，塞进去它会整个文件报错
- [x] 「停用」只对确认认这个开关的格式开放，不认的直接挡住并说明原因
- [x] 远端 server（URL / headers）读得出来但不写，报 `remoteReadOnly` / `headersUnsupported`，不猜
- [x] 写入三件套：写前备份 `.bak`、指纹校验挡外部改动、原子写
- [x] 每一种挡写原因都有中文说明（不支持 / 没有可写来源 / 不在可写来源里 / 没有启停开关 / 定义不完整 / 远端只读 / headers 不支持）

## 三、Skills 面板

**核心决策：不新建 store，认领已有的。** 本机原本有三套 store 互不知情，绝不能再开第四个。

- [x] 扫全部 store + 七家 agent 的 skills 目录，算出实体目录 / 链接 / 断链 / 两跳链 / 环 / 重复
- [x] 主 store 可选、可新增、可移除；一个都没有时兜底到 `~/.agents/skills`（哪怕还不存在也要出现在下拉里）
- [x] 公共目录 `~/.agents/skills` 是一等公民 —— 哪怕主目录不是它，也要在它里面建链接
- [x] **收编**（界面上叫「搬进主 store」）：把散落的实体目录归拢，单条 + 全部两个入口
- [x] **删除即全量解链**：先解链再删源，顺序固定 —— 反过来链接瞬间全变死链，而那时已经没有信息知道该去哪清理
- [x] **每一份内容单独删**：同一个 skill 在全局和项目各有一份时，可以只删一边
- [x] 单条链接解绑（`unlinkRef`）
- [x] 健康修复：一键清死链
- [x] 按 agent 启停（建/删链接），列全部已装 agent，不支持的置灰并说明原因
- [x] 「保留内容」开关，两个方向都二次确认
- [x] 从 GitHub 装来的 skill 有「来自 github」角标，能查更新、能更新；会被覆盖的本地改动在计划里列清楚，不跑 `git clean`
- [x] 风险引擎：按命中位置分四档降权（可执行脚本 0 / 注释 1 / 代码块 1 / 散文 2）—— 不降权的话说明文档会全被报成 Critical，角标全红等于没有角标
- [x] 内置编辑器：文件树 + 编辑 / 预览双栏 + 保存 + 「用外部编辑器打开」。**不引 Monaco / CodeMirror**，用仓库已有的 shiki 自己搭
- [x] 收编冲突三选一：保留主 store / 用外部这份 / 两份都留；带逐行 diff，可跳过、可全部跳过
- [x] 所有写操作都是 dry-run → 计划框 → 用户点了才真跑；任一步失败全部回滚
- [x] 排序：时间倒序 / 时间正序 / 按名称，**置顶不受影响**；切换后滚动位置归 0
- [x] 置顶、搜索、agent 过滤、在文件管理器中显示
- [x] 受管副本（Windows copy 降级）的健康态分开算：新鲜 / 只有源变了 / 副本被就地改过 / 两边都变了 / 源没了。**只有「只有源变了」给一键重拷** —— 别的几种重拷会把用户的改动抹掉

## 六、全局配置面板（AGENT.md / CLAUDE.md）

- [x] 导出：MCP / hooks / 全局指令三块，打码项单列并说明为什么

## 八、跨平台链接

- [x] 三级降级：symlink → junction（Windows）→ 受管副本
- [x] junction 用 `DeviceIoControl`，**不走 `cmd /C mklink /J`** —— cmd 的引号规则不同，路径含 `&` `^` `%` 有注入风险，且批量建链会开一堆进程
- [x] 受管副本有 marker 文件，且 marker 必须是**普通文件**（`fs::read` 会跟随 symlink，一条指向别处合法 marker 的链接就能让任意目录看起来受管）
- [x] marker 里记 `copy_path`，位置对不上就不认
- [x] 删除前先 `symlink_metadata` 查类型，只删对得上的那一种
- [x] 降级复制那一级刻意写成平台无关的，macOS 单测就能覆盖到 —— 它是整个模块里最危险的一段

## 改这块必须守的

- **后端独占 I/O。** 所有文件读写、解析、链接操作都在 `src-tauri/src/tools/`，前端只负责渲染和拼参数
- **新命令三件套**：`lib.rs` 定义 → `generate_handler!` 注册 → `api.ts` + `types.ts` 暴露
- **不在 `lib.rs` / `trash.rs` 里写 per-agent 的 match 分支。** 装不上 trait 说明 trait 形状不对，改 trait
- **能力位放后端，不放 `agentMeta.ts`。** 两处各说一套会造出「UI 说有、后端说没有」的空面板
- **可测逻辑抽成 `src/tools*.ts`。** `views/` 和 `modals/` 在 `vitest.config.ts` 里是覆盖率排除的，写进 `.vue` 就再也测不到
- **scoped 类名不是复用契约。** 照着另一个面板抄类名、渲染出来没样式，这个坑踩过三次
- **所有写操作先 dry-run 出计划，用户点了才跑；写前备份、指纹校验挡外部改动、原子写**
- **零新增 npm / cargo 依赖**
- **不留兼容层。** 改形状就改干净，删掉过时的 state / emit / storage key
- **四道闸全绿**：`npx vue-tsc --noEmit`、`npm run test:run`、`cargo clippy -- -D warnings`、`cargo test`

## 没做 / 不做

- **Windows 真机验证矩阵没跑。** 手上没有 Windows 机器。三级降级的逻辑有单测覆盖，
  但「在真的 Windows 上建 junction、在真的 Dev Mode 关闭状态下降级到 copy」这件事没有实证
- **「新建 skill」没做。** 装和改都有了，从零建一个还得去终端
- **不做 MCP 商店 / 一键装一切。** 单个工具定义占 200–500 token，5–10 个 server 在用户敲第一个字之前就烧掉 100k+ 上下文。我们要做的是反过来的事
- **不自动合并全局指令的分叉。** 有意分叉是完全合理的（给 Codex 的版本故意写得更短）
- **不管 Grok 自己的 worktree 注册表**
